# Go-to-Market — Whiskey Club

## Estratégia em 3 ondas

### Onda 0 — Alpha fechado (clube parceiro único)
- 1 clube parceiro real (escolhido com o sponsor).
- Critério de saída: dono usa por 30 dias sem WhatsApp na operação core; sócios dão NPS ≥ 50.

### Onda 1 — Beta convidado (3–5 clubes)
- Apresentação 1-a-1, white-glove onboarding.
- Preço promocional Founders (50% por 6 meses + setup grátis).
- Critério de saída: 80% dos clubes renovam, churn de sócios < 5%/mês.

### Onda 2 — Lançamento público
- Site institucional whiskeyclub.app.
- Landing pages SEO para "app para clube de whiskey", "white label clube assinatura premium".
- Conteúdo (blog + LinkedIn) feito pelo agente Tech Writer + curador (Otto).
- Programa de parceria com sommeliers e distillerias importadoras.

## Funil B2B

```
Lead (sommelier, dono de clube)
  → Demo agendada
  → Sandbox provisionado (10 min, automático)
  → Proposta + setup
  → Cliente assinado
```

## Funil B2C (dentro do clube já onboardado)

```
Sócio existente
  → Convite por e-mail/WhatsApp (campanha lançada pelo dono via backoffice)
  → Download do app
  → Ativação (carteirinha)
  → Primeira presença em evento via app
  → Repeat (objetivo: 2ª presença em 30d)
```

## Materiais de lançamento

- **Landing institucional** (whiskeyclub.app).
- **Demo vídeo** 90s (gerado pelo agente Designer + Tech Writer).
- **Pitch deck** 12 slides (PM + Designer).
- **One-pager** PDF brandado por flavor (gerado por template).
- **Onboarding kit do clube novo**: checklist + vídeos curtos.

## Métricas de lançamento

| Métrica | Meta Beta | Meta Lançamento (90 dias) |
|---|---|---|
| Clubes ativos | 3 | 10 |
| Sócios ativos totais | 600 | 2500 |
| MRR | R$ 4k | R$ 18k |
| Activation rate (sócios) | 70% em 14d | 65% em 14d |
| Repeat rate evento | 50% | 55% |
| NPS sócio | 50 | 60 |
| Churn de clube/mês | < 5% | < 3% |

## Riscos de lançamento

- **App rejection**: ter o app dos clubes nas stores leva tempo. Começar processo em paralelo ao dev.
- **Curva de aprendizado do dono**: prever sessão de onboarding sob demanda.
- **Picos em primeiro evento via app**: ensaiar com carga sintética (k6) por clube novo antes do go-live.
