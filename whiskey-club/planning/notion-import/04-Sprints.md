# 04 — Sprints / Ciclos

Trabalhamos em **ciclos de 2 semanas** (chamados aqui de "Sprints" por familiaridade, mas sem dogma).

## Database — Sprints

| Propriedade | Tipo |
|---|---|
| Nome | Título (Sprint 1, ...) |
| Início / Fim | Date range |
| Objetivo | Texto (1 frase) |
| Capacidade | Number (pontos) |
| Comprometido | Rollup (sum pontos das stories) |
| Concluído | Rollup |
| Velocidade média (3 últimas) | Formula |
| Status | Select (Planejando / Em andamento / Encerrado) |

## Rituais por sprint

| Dia | Ritual | Quem |
|---|---|---|
| D0 | Planning | PM + PO + Tech Lead + leads |
| Diário | Standup assíncrono | Todos |
| Meio | Refinamento | PM + PO + BA + Tech Lead + UX |
| D-1 | Review + Demo | Todos + sponsor |
| D-1 | Retro | Todos os agentes |
